# Atlas Agroalimentaire — applications

Installateurs officiels de l’**Atlas Agroalimentaire**, plateforme scientifique sur les aliments, les fermentations, les procédés
et la sécurité des aliments : <https://atlas-agrofood.netlify.app>.

Ce dépôt ne contient **que les fichiers d’installation** publiés dans les [Releases](https://github.com/kerobero0311/atlas-agroalimentaire-applications/releases)
(aucun code source, aucune donnée privée). Le site et les applications partagent les mêmes données.

Empreintes SHA-256 : fichier `SHA256SUMS.txt` de la release (PowerShell : `Get-FileHash <fichier> -Algorithm SHA256`).

- **Windows** : installateurs non signés — SmartScreen affiche « Windows a protégé votre ordinateur » : « Informations complémentaires »
  puis « Exécuter quand même ». Les mises à jour suivantes sont proposées automatiquement par l’application.
- **Android** : autoriser l’installation depuis cette source, puis ouvrir l’APK.
- **Sans installation** : le site fonctionne dans tout navigateur récent et peut être installé comme application (PWA).

Contributions (nouvelles fiches, corrections, sources) : bouton « + Ajouter une fiche » dans l’application ou sur le site ;
elles sont vérifiées avant publication.
